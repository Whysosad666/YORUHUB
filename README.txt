Как запустить:
1. Открой папку yoru-hub-static
2. Нажми два раза на index.html

Постеры добавляй сюда:
posters/
В форме добавления указывай путь например:
posters/dxd.jpg
posters/aot.png

======================================================
Обновление 2: баннер, уровни, автозаполнение
======================================================

1. Колокольчик (уведомления) убран из шапки.
2. На баннере теперь летают маленькие частицы — их цвет автоматически
   меняется вместе с темой сайта (красная/фиолетовая/синяя).
3. Баннер полностью пересобран: Риас теперь ближе к центру, Акено
   добавлена слева, обе картинки без белого фона, с плавным затуханием
   по нижнему краю, плюс фоновая текстура и свечения в цвет темы —
   всё сливается с общим фоном сайта, а не выглядит "вставленным поверх".
4. Японская подпись заменена на английскую (RIAS GREMORY / A queen
   never yields.) и перемещена в промежуток между персонажами, чтобы
   не перекрывать ни одного из них.
5. Система уровней вернулась, но по новому правилу: 1 уровень = 2
   полностью просмотренных аниме (статус "Просмотрено"). Прогресс
   виден в шапке (тонкая полоска под именем) и подробно расписан на
   странице "Статистика".
6. В форму "Добавить аниме" добавлено поле "Возрастной рейтинг"
   (0+/6+/12+/16+/18+) — отображается бейджем в списке аниме.
7. Число серий подтягивается автоматически: если в поле "Ссылка где
   смотреть" вставить прямую ссылку на страницу аниме на MyAnimeList
   (myanimelist.net/anime/...), при уходе из поля сайт сам подставит
   количество серий (и год, если пусто). Это работает через открытый
   публичный API Jikan — нужно интернет-соединение в браузере. Если
   вставить не MAL-ссылку, а обычное название в поле "Название" и
   оставить поле "Эпизодов всего" пустым — сайт попробует найти его
   по названию при уходе с поля. Число сезонов автоматически определить
   у открытых API нет возможности, поэтому оно осталось ручным полем
   (по умолчанию 1).
8. Раздел "Календарь" заменён на "Новинки" — там показываются 5
   последних полностью просмотренных аниме.
9. В блоке "Продолжить просмотр" (и в "Новинках") вся карточка теперь
   кликабельна — нажатие сразу открывает ту ссылку, которую вы
   указали при добавлении аниме.
